# Mitmachen

Danke für dein Interesse an diesem Projekt! So kannst du helfen:

## Fehler melden oder Skill-Wunsch äußern

Am einfachsten über ein [Issue](../../issues/new/choose) — dafür gibt es passende Vorlagen für Fehlerberichte und Skill-Wünsche.

## Verbesserungen an bestehenden Skills

Kleine Fixes (Tippfehler, unklare Formulierungen in einer SKILL.md, veraltete Links) gerne direkt als Pull Request. Bitte:

1. Nur eine Änderung pro Pull Request.
2. Kurz beschreiben, was und warum geändert wurde.
3. Bestehende Struktur beibehalten (ein Ordner pro Skill unter `skills/`, mit eigener `SKILL.md`, `LICENSE` und ggf. `README`).

## Neue Skills

Dieses Repository ist eine kuratierte Sammlung — jeder Skill hier wurde vorher selbst im Alltag bei KI-Wissen.org genutzt und getestet, bevor er veröffentlicht wurde. Neue Skills werden aktuell nicht per Pull Request von außen aufgenommen, aber Vorschläge sind über ein Issue jederzeit willkommen und fließen in die Planung ein.

## Verhalten

Für Issues und Pull Requests gilt unser [Code of Conduct](CODE_OF_CONDUCT.md).
