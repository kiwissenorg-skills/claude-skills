# Skill-Center

> Version 1.3.1 · Community · ein Skill von KI-Wissen.org

## Was dieser Skill für dich tut

Die Kommandozentrale für professionelle Skill-Entwicklung: ein Ort, an dem vorhandene Skills ausgewertet, überarbeitet, neu entwickelt, automatisch getestet, dokumentiert, versioniert und kundenreif ausgeliefert werden. Ein Skill verlässt das Skill-Center laut Grundprinzip erst, wenn er getestet, dokumentiert und freigegeben ist. Alte Versionen werden nie überschrieben, sondern archiviert; ein zentrales Register hält Version, Status, Test- und Kundenstand aller Skills fest.

## Wann der Skill reagiert

Der Skill löst aus, wenn du z. B. schreibst:
- „Skill-Center: werte alle meine Skills aus."
- „Bau mir einen Skill, der …"
- „Teste Skill X und gib mir den Testbericht."
- „Liefere Skill X für meinen Kunden aus."
- Oder bei „Skill überarbeiten", „neue Version", „Skill-Register", „ist der Skill kundenreif".

## Installation

1. Diesen Ordner (`SKILL.md` + `references/`) herunterladen.
2. In Claude (Cowork mit Zugriff auf einen Speicher-Ordner) als eigenen Skill hinzufügen.
3. Los — beim ersten Start legt das Skill-Center automatisch den Arbeitsordner `Speicher/Skill-Center/` mit Register-, Skills-, Archiv- und Auslieferungs-Unterordner an.

## Die sechs Befehle

1. **Auswerten** – Audit vorhandener Skills mit Ampel-Urteil und konkreten Optimierungsvorschlägen.
2. **Überarbeiten** – Skill verbessern, neue Versionsnummer, alte Version wandert ins Archiv.
3. **Neu bauen** – aus einer Beschreibung einen neuen Skill als v1.0 erstellen.
4. **Testen** – automatische Eval-Suite, Testbericht, Freigabe nur bei 100 % bestandenen Tests.
5. **Dokumentieren** – Kunden-README, mit der der Kunde allein klarkommt.
6. **Ausliefern** – freigegebenen Skill als `.skill`- oder `.plugin`-Paket verpacken.

## Voraussetzungen

Cowork-Desktop-App mit Zugriff auf den Speicher-Ordner. Nutzt den vorhandenen `skill-creator` als Test-Engine.
