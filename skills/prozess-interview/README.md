# Prozess-Interview

> Community · ein Skill von KI-Wissen.org

## Was dieser Skill für dich tut

Verwandelt eine noch unklare Idee, einen Ablauf oder ein geplantes Vorhaben in einen klaren, umsetzbaren Plan — durch ein ruhiges, geführtes Gespräch, bevor irgendetwas gebaut oder umgesetzt wird. Der Skill stellt dabei immer nur eine Frage pro Nachricht, ohne Fachjargon, und spiegelt nach jeder Antwort kurz, was er verstanden hat. Am Ende entsteht ein strukturierter Prozess-Steckbrief direkt im Chat (optional zusätzlich als Word-Dokument).

## Wann der Skill reagiert

Der Skill löst aus, wenn du z. B. schreibst:
- „Ich möchte X erstellen."
- „Ich will Y automatisieren."
- „Hilf mir Z zu planen."
- „Neuer Prozess" / „Ablauf festlegen" / „Workflow definieren."
- „Ich habe eine Idee für …", „ich weiß noch nicht genau wie."

Er reagiert **nicht** bei einer einzelnen, eindeutigen Mini-Aufgabe, die sich sofort erledigen lässt.

## Installation

1. `SKILL.md` aus diesem Ordner herunterladen.
2. In Claude (Cowork, Claude Code oder Claude Desktop) als eigenen Skill hinzufügen.
3. Los — beschreib dein Vorhaben in ein, zwei Sätzen, der Skill übernimmt den Rest des Interviews.

## Anwendungsbeispiele

**Beispiel 1**
Du: „Ich will automatisch auf Kundenanfragen antworten, weiß aber noch nicht genau wie."
Ergebnis: Der Skill fragt Schritt für Schritt nach Zielgruppe, heutigem Ablauf, gewünschtem Ergebnis, Regeln/Ausnahmen und einem konkreten Beispiel, bevor er einen vollständigen Prozess-Steckbrief ausgibt.

**Beispiel 2**
Du: „Neuer Prozess: Rechnungsfreigabe im Team."
Ergebnis: Bei einem kleinen, klaren Vorhaben stellt der Skill nur 2–4 Kernfragen und fasst danach zur Bestätigung zusammen, statt ein langes Interview durchzuziehen.

## Voraussetzungen

Keine — der Skill benötigt keine externen Werkzeuge oder Integrationen. Für ein optionales Word-Dokument des Steckbriefs ist die docx-Fähigkeit von Claude hilfreich, aber nicht zwingend (die Chat-Ausgabe ist immer vollständig).

## Wenn etwas nicht klappt

- Der Skill fragt zu viel / zu wenig? → Die Tiefe passt sich automatisch an die Komplexität des Vorhabens an; bei sehr einfachen Anliegen reichen 2–4 Fragen.
- Der Steckbrief passt nicht? → Vor der Erstellung fasst der Skill das Verständnis zusammen und fragt nach — erst nach einem klaren „Ja" wird der Steckbrief erstellt.
- Willst du direkt eine eigene Skill/Automatisierung daraus bauen? → Der Skill ergänzt auf Wunsch einen „Bauplan"-Abschnitt, den du an eine Skill-Erstellungs-Skill übergeben kannst.
