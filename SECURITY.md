# Security Policy

## Meldung von Sicherheitsproblemen

Solltest du eine Sicherheitslücke in einem der Skills finden (z. B. ein Skill, der unbeabsichtigt sensible Daten verarbeitet, ausliest oder weitergibt), melde das bitte **nicht** als öffentliches Issue.

Schreib stattdessen direkt an: **kiwissenorg@gmail.com** — Betreff „Security: claude-skills".

Bitte gib an:

- Welcher Skill betroffen ist.
- Eine kurze Beschreibung des Problems und, falls möglich, Schritte zum Nachvollziehen.
- Deine Einschätzung zur Schwere (z. B. Datenverlust, Datenabfluss, unerwartete Kosten).

## Was danach passiert

Rückmeldung erfolgt in der Regel innerhalb weniger Tage. Nach Behebung wird das Problem — sofern sinnvoll — anonymisiert in einem Release-Hinweis dokumentiert.

## Umfang

Dieses Repository enthält reine Anleitungsdateien (`SKILL.md` + Zusatzdateien) ohne eigenen Server-Betrieb. Es werden keine Nutzerdaten durch dieses Repository selbst verarbeitet oder gespeichert — die Skills laufen lokal in der jeweiligen Claude-Umgebung des Nutzers.
